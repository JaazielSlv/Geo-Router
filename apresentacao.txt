ROTEIRO DE APRESENTAÇÃO - GEO ROUTE

Bom dia/tarde, nós somos a equipe responsável pelo projeto Geo Route.

O objetivo da aplicação é oferecer uma plataforma para visualização, busca e administração de Sistemas Autônomos (AS), reunindo back-end, banco de dados e autenticação em uma solução integrada.

1. Visão geral do projeto
Nosso projeto foi desenvolvido com Node.js, Express, Prisma, MySQL e JWT. A aplicação permite consultar dados de AS, visualizar métricas, realizar cadastro e login de usuários e administrar registros de forma autenticada.

2. Back-end com Express.js
O back-end foi estruturado de forma modular, utilizando rotas para separar as responsabilidades, controllers para a lógica de cada recurso e middlewares para autenticação e tratamento de requisições. A validação de entradas foi implementada com express-validator, garantindo que dados inválidos sejam rejeitados antes de chegarem ao banco de dados. O tratamento centralizado de erros foi feito em um middleware específico, que transforma exceções em respostas adequadas para a API, com status HTTP e mensagens claras.

3. Banco de dados e persistência de dados
O banco de dados foi modelado com Prisma e MySQL. Criamos entidades como User e AutonomousSystem, com estrutura organizada para armazenar informações de sistemas autônomos e usuários. Utilizamos o ORM para criar, consultar, atualizar e remover registros, além de facilitar a manutenção do schema e a evolução do banco com migrations e configuração centralizada do cliente Prisma.

4. Autenticação e controle de acesso
O cadastro e o login de usuários foram implementados com validação de e-mail e senha. As senhas são armazenadas de forma segura com hash utilizando bcrypt. Os tokens JWT são gerados no login e utilizados para proteger rotas autenticadas, garantindo que apenas usuários autorizados possam criar, editar ou excluir registros.

5. Configuração e segurança
A aplicação utiliza variáveis de ambiente para armazenar informações sensíveis, como URL do banco de dados, segredo JWT e porta do servidor. Essas configurações foram mantidas fora do código-fonte, seguindo boas práticas de segurança e facilidade de implantação.

6. Docker, documentação e testes
Também implementamos Docker e Docker Compose para facilitar a execução do projeto, incluindo banco de dados e aplicação em containers. A documentação da API foi disponibilizada com Swagger, e testes automatizados foram adicionados para validar o funcionamento principal da aplicação.

7. Conclusão
Em resumo, o Geo Route é uma aplicação back-end robusta, com persistência em banco de dados, autenticação segura e uma estrutura organizada, pronta para demonstrar os conceitos aprendidos na disciplina.
